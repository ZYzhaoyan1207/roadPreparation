# roadPreparation - Road Network Format Converter for Diverse Shortest Path Algorithms

This repository converts real-world road network data from 12 selected cities—originally provided by Karduni et al. (2016) in their Scientific Data paper(https://www.nature.com/articles/sdata201646) — into a unified format suitable for testing and evaluating diverse shortest path algorithms.

## Data Source

The raw data is sourced from the Figshare repository published alongside the paper: https://dx.doi.org/10.6084/m9.figshare.2061897.v1

This dataset is derived from OpenStreetMap and contains road networks for the 80 most populated urban areas worldwide. For this project, 12 cities were selected to serve as testbeds for diverse shortest path algorithm research.

## Selected Cities (12)

Dongguan, Fuzhou, Dalian, Qingdao, Tianjin, Shenzhen, Beijing, Dhaka, Medellin, Karachi, Mumbai, Delhi

## Repository Structure

**sourceData/**  
Contains the original data downloaded from Figshare (zipped or extracted).

**roadAlter.py/**  
Conversion script that standardizes raw network files into a unified .gr format.

**roadOut/**  
Contains the standardized .gr network files for the 12 selected cities generated by `roadAlter.py`.  
`road.gr` file format:
- First line: [num_nodes] [num_edges] (nodes and edges count)
- Following lines: [start_node] [end_node] [weight] (each line represents one directed edge)
